CSS Symposium 2026 website

Files:
- index.html
- styles.css
- script.js
- assets/

To publish with GitHub Pages, upload index.html, styles.css, script.js and the entire assets folder to the repository root.

IMPORTANT: In index.html, replace the two href="#" values carrying data-placeholder="registration" and data-placeholder="abstract" with the live registration and abstract submission URLs.

The page is responsive and requires no framework/build step. Google Fonts is used for Inter; if unavailable, it falls back to Arial/sans-serif.
